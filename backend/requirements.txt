# Sentinel Nexus backend.

# Deliberately absent:
#   PyTorch  -- detection runs YOLO11 on ONNX Runtime, and OpenCV DNN is the
#               fallback. Neither needs Torch, which additionally clashes with
#               PaddlePaddle over DLLs on Windows when both load in one process
#               -- and PaddleOCR is not optional here, it reads the burned-in
#               overlay clock every event timestamp comes from.
#   ultralytics -- pulls Torch in transitively, for an API we do not need once
#               the weights are exported.
#   Anaconda -- use a clean venv; a --system-site-packages venv mixes numpy-1.x
#               compiled wheels with numpy 2.x and breaks pandas at import.
#
# PaddleOCR pulls imgaug + albumentations transitively and imports both
# unconditionally, so neither can be removed. scikit-learn CAN be removed.
